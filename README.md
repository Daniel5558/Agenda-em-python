# Agenda-Em-Python


Agenda de Contatos
Projeto desenvolvido para praticar o uso de dicionários em Python.
O programa permite adicionar, remover, buscar e listar contatos através de um menu interativo no terminal.
Funcionalidades:

Adicionar contato
Remover contato
Buscar contato por nome
Exibir todos os contatos

Tecnologias: Python 3
